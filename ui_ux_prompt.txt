## Generator Prompt Specification

Build a premium, responsive, and visually delightful web interface for "The End-to-End Agentic Prototyping Pipeline" utilizing a premium, modern Light Theme. The interface must include a dynamic initial Splash Screen Gateway that splits into three distinct role-based sub-systems (Admin Architect, Principal Planner, and Implementer Sandbox).

### 1. AESTHETICS & EMOTIONAL SYSTEM THEME
- **Visual Feel:** "Intelligent Engineering Canvas." Designed to look like a premium, clean, high-performance IDE and architecture canvas—highly professional, precise, and visual. Translucent white panels, lavender highlights, mint code validation logs, and drop shadows encourage strict focus on design logic and code generation.
- **Color Palette (Light Glassmorphic):**
  * Canvas Base Background: Crisp Soft Studio Grey (#f8fafc)
  * Panel Backgrounds: Milky Translucent Acrylic (rgba(255, 255, 255, 0.75))
  * Borders: 1px thin outlines with dynamic active gradients (linear-gradient(135deg, rgba(139, 92, 246, 0.2), rgba(6, 182, 212, 0.15)))
  * Primary Accent: Lavender Purple (#8b5cf6)
  * Secondary Validation Accent: Mint Green (#10b981)
  * Warning Indicators: Sunset Coral (#f43f5e)
  * Muted Details: Slate Grey (#64748b)
- **Glassmorphic Filter:** `backdrop-filter: blur(14px)`
- **Filters & Shadows:** box-shadow: `0 8px 32px rgba(100, 116, 139, 0.05)`.
- **Typography:** Space Grotesk (headers and C4 diagram labels), Inter (code logs and forms).

### 3. ROLE-BASED UI/UX BOARDS (POST-LOGIN PATHS)

#### A. THE ADMIN ARCHITECT DECK (POST-LOGIN ROLE: ADMIN ARCHITECT)
- **Layout Grid:** 12-column grid. Left Navigation Sidebar: 3 columns. Center Data Hub: 9 columns. Inner padding: p-6 (24px). Gap: 20px.
- **Controls & Widgets:**
  - **Vector Database Monitor:** Frosted table displaying active PostgreSQL `pgvector` index statistics (Cosine Similarity embeddings counts, HNSW indexing performance sparklines).
  - **Tree-sitter AST Parser Logs:** Real-time log console visualizing codebase index parsing, function imports, and syntax trees.
  - **Re-indexing Action Button:** "Rebuild Codebase Semantic Index" (Lavender background, white text, padding: 12px 24px, hover: translate-y(-1px)).

#### B. THE PRINCIPAL PLANNER DECK (POST-LOGIN ROLE: PLANNER)
- **Layout Grid:** 12-column grid. Sidebar (Elicitation Chat): 4 columns. Main Canvas (C4 Diagram): 8 columns. Inner padding: p-8 (32px).
- **Controls & Widgets:**
  - **Architect Solutions Elicitation Chat:** Frosted chat dialog panel listing dialogue turns between the architect agent and the user. Input bar with dynamic prompt tags.
  - **The Blueprint Stage (C4 Diagram):** Giant centered interactive canvas displaying visual C4 system diagrams rendered from D2/Mermaid syntax. Includes:
    1. Zoom and pan interactive controls.
    2. Dynamic block components (interactive drag-and-drop boxes representing databases, servers, APIs).
    3. Action Button: "Approve Architecture spec" (Mint Green gradient background, white text, padding: 14px 24px).

#### C. THE IMPLEMENTER SANDBOX (POST-LOGIN ROLE: IMPLEMENTER/VERIFIER)
- **Layout Grid:** Stacked double-column display.
  - Left Panel (Implementer Terminal): 6 columns.
  - Right Panel (Verifier Code Auditor): 6 columns. Inner padding: p-6 (24px).
- **Controls & Widgets:**
  - **Sandboxed Docker Terminal:** Interactive terminal box displaying real-time command loops, local test runs (`stderr`/`stdout`), and file writing alerts.
  - **Static Security Audit Dashboard:** Bulleted report card listing automated code verification checks ("Stripe header signature verified", "Error handlers validated").
  - **Adversarial Punch-list Interface:** Display panel containing verified code diffs alongside red compiler warnings. Action Button: "Re-generate File" (Sunset Coral border, text, hover: bg-red-500/10).
  - **Success PR Opener:** Floating card rendered upon complete audit checks, presenting a button: "Generate GitHub Pull Request" (Mint Green background, white text).
