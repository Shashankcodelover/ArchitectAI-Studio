# Contributing to ArchitectAI Studio

Thank you for contributing!

## Development Workflow
1. Fork the repository and create your feature branch (`git checkout -b feature/amazing-feature`).
2. Verify backend (`cd ai-architect-backend && npm run dev`) and frontend (`cd ai-architect-frontend && npm run build`).
3. Open a Pull Request for code review.

## Security Notice
Do not commit Gemini API keys or internal environment secret tokens.
